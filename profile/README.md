# ✨ Welcome to CogSoma ✨

**Every rig within reach.**

## About CogSoma

CogSoma is a toolkit that makes the neuroscience lab automated and digital, so people and AI agents can sense, operate and manage experiments directly. It covers the whole path: reach a rig from anywhere, run an experiment on it, and keep every animal, session and file in one record. It grew out of [CageLab](https://github.com/cagelab), and runs home cage experiments on CageLab and MXBI rigs.

## 🚀 The components

- **CogMatrix** - an animal-centred database for the whole lifecycle: animals, care records, devices, sessions and their data, with a web workbench and a GraphQL API.
- **cogmote** - control and live view of remote rigs: experiments, video, remote desktop and deployment, from a web app or a command line.
- **cogmoteGO** - the service on every rig, for status, live data, commands and video. **pymoteGO** and **matmoteGO** connect Python and MATLAB task code to it.
- **CogID** - one sign-in for every tool, with passkeys and invitations.
- **cognotify** - notifications by email, ntfy and Telegram.
- **coginfra** - one command to deploy all of it on a lab server.
